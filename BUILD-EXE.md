# Сборка StampGen в готовый EXE (для распространения)

## Windows (основной вариант для «простых пользователей»)

Нужен установленный [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
(или просто SDK — рантайм включается в exe автоматически).

Откройте PowerShell в папке проекта (`StampGen\`) и выполните:

```powershell
.\build-exe.ps1
```

Скрипт сам выполнит публикацию и подскажет, где лежит результат:

```powershell
# то же самое вручную:
dotnet publish StampGen\StampGen.csproj -c Release -r win-x64 -o publish\win-x64
```

Результат — папка `publish\win-x64`:
- `StampGen.exe` — запускается двойным кликом, сам поднимает локальный сервер
  на свободном порту (5317…) и **открывает браузер автоматически**.
- `wwwroot\` — статические файлы (база иконок, шрифты, JS). Их нужно держать
  рядом с exe (можно распространять всей папкой в zip).

> Хотите **один-единственный файл** без папки wwwroot: добавьте флаг
> `-p:IncludeAllContentForSelfExtract=true` — всё будет упаковано внутрь exe
> (exe станет тяжелее и будет чуть дольше стартовать: он распаковывает
> файлы во временный каталог при запуске).

## Linux / macOS

```bash
./build-exe.sh          # linux-x64 (или поправьте RID на osx-x64 / osx-arm64)
```

## 🔒 Обфускация (защита от реверс-инженеринга) — опционально

Обычная сборка выше уже содержит базовую защиту: **single-file exe без PDB-файлов**
(DebugType=none в Release — декомпиляция IL без отладочных символов заметно сложнее).

Для усиленной защиты (переименование приватных типов/методов + шифрование строковых
литералов) добавьте флаг `-Obfuscate` — используется свободный обфускатор
[Obfuscar](https://github.com/obfuscar/Obfuscar) (MIT, настройки в `obfuscar.xml`):

```powershell
dotnet tool install --global Obfuscar.GlobalTool   # один раз
.\build-exe.ps1 -Obfuscate
```

Что важно знать:

- Обфусцируется **только сборка программы** (`StampGen.dll`), сторонние библиотеки
  не трогаются. Публичное API и имена свойств/полей **не переименовываются**
  (`KeepPublicApi=true`) — Blazor-компоненты, `[JSInvokable]` и сериализация
  проектов `.stampgen` продолжают работать.
- В режиме обфускации exe публикуется **папкой** (не single-file): Obfuscar должен
  достать `StampGen.dll`; распространяйте папку `publish\win-x64` в zip — это
  штатный способ из README.
- **Обязательно проверьте** обфусцированную сборку перед выкладкой: запуск,
  импорт библиотеки, оттиск, STL, «О программе».
- Честное ограничение: обфускация сильно усложняет анализ кода, но не делает его
  теоретически невозможным; юридическая защита — `LICENSE.md` и `AGENTS.md`,
  а аттестация владельца (SHA-256 ключа в `OwnerGuard.cs`) описана в
  `docs/OWNER-ATTESTATION.md`.

## Параметры запуска exe

| Параметр | Значение |
|---|---|
| `--port=N` | задать порт (по умолчанию первый свободный из 5317–5322) |
| `--no-browser` | не открывать браузер автоматически |
| переменная `STAMPGEN_PORT=N` | то же, что `--port` |
| переменная `STAMPGEN_NO_BROWSER=1` | то же, что `--no-browser` |

## Что делает exe

1. Запускает встроенный сервер Blazor (Kestrel) на `http://127.0.0.1:ПОРТ`.
2. Открывает браузер по умолчанию на этом адресе.
3. Работает полностью локально: интернет не нужен, данные никуда не уходят.
